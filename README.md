#  Moonflix

Moonflix is a prototype of a streaming platform developed in **C++**.  
The project simulates the basic functionalities of a streaming service, allowing users to:

- Explore a content catalog.  
- View details of movies and series.  
- Manage playlists in a simple way.  

---

## Project Structure

The repository contains the following main files:

- `Netflix.cpp` / `Netflix.h`: Core logic of the application.  
- `Película.cpp` / `Película.h`: Implementation of the **Movie** class.  
- `Serie.cpp` / `Serie.h`: Implementation of the **Series** class.  
- `Video.cpp` / `Video.h`: Base class **Video**, inherited by movies and series.  
- `Datos.txt`: Data file with the initial catalog.  
- `Moonflix`: Executable file generated after compilation.  
- Project configuration files (`.sln`, `.vcxproj`) for Visual Studio.
